# 이미지 상점 구성

기준 브랜치: feature/prototype (`775dd9e`)
작업 브랜치: codex/shop-image-assets

## 가져온 이미지

원본은 별도 테스트 프로젝트 `Mangofit_mangotest1/app/src/main/res/drawable-nodpi`에 있다.
원본을 수정하지 않고 PNG 164개를 같은 리소스 디렉터리로 복사했다.

- 성장 색상 5단계 × 기본 망고와 의상 10종 (55개)
- 기본 미소 표정 (1개)
- 손 아이템 18종 × 좌우의 `_preview`, `_tint`, `_detail` 이미지 (108개)

망고 레벨 1·3·5·7·9에서 초록, 연두, 노랑, 황금빛 노랑, 오렌지로 익는다.
같은 의상의 성장 단계별 이미지를 선택한 뒤 저장된 색상을 적용한다.
망고집에서는 보관 당시 경험치로 성장 단계를 표시한다.
의상 PNG는 몸체까지 포함하므로 본체 이미지 자체를 교체하고 표정을 겹친다.
손 아이템은 테스트 프로젝트의 기본 배치를 망고 이미지 너비 기준 비율로 옮겼다.
개별 아이템 배치는 `ItemCatalog`의 `Placement`에서 조정한다.

## 상품과 가격

새 의상 10종, 오른손 18종, 왼손 18종을 판매한다. 모자는 상점·꾸미기 탭과 모든 망고 표시에서 제외한다. 기존 모자 데이터는 호환용으로 보존한다.
임시 가격은 일반 의상 500, 곤룡포 800, 손 아이템 각 300 이파리다.
좌우 아이템은 별도 상품으로 구매하고 각각 장착한다.
`ItemCatalog`에서 가격·배치를, `strings.xml`에서 상품명을 관리한다.

상품 카드를 누르면 현재 장비와 함께 착용 미리보기를 볼 수 있다.
가격 버튼에서 구매를 확인하고, 보유 중 버튼을 누르면 꾸미기 화면으로 이동한다.
꾸미기에서 적용하면 홈·기록·망고집의 공통 `MangoView`에도 반영된다.

## 저장 호환성

기존 `hat`, `top`, `hand` 키와 아이템 ID는 유지한다. `hand`는 오른손 슬롯이다.
왼손은 SharedPreferences의 `equip_left_hand`, 보관 JSON의 `left_hand`에 저장한다.
예전 저장 파일에 왼손이 없으면 미장착 상태로 읽는다.
기존 상의·손 아이템은 신규 판매 목록에서 제외하되, 보유 목록과 장착은 유지한다.
기존 보관 시 아이템 소모 규칙은 왼손에도 동일하게 적용한다.

## 색상 선택과 tint

상품 그림 오른쪽 아래의 팔레트 버튼을 누르면 원본과 상품별 추천색을 고를 수 있다.
선택 중에는 큰 미리보기에만 적용하고, 취소하면 기존 색을 유지한다.
의상·손 아이템 모두 제한된 파스텔 팔레트를 제공한다.
버블티는 말차·로즈·타로·바닐라, 치킨은 허니·로스트·코코아 등 재질에 맞춰 구성했다.
팔레트의 색상 코드와 적용 대상은 `ItemPalette`에서 관리한다.

- 손 아이템: 제공된 `_tint`의 범위를 원본 명암과 결합해 MULTIPLY tint를 적용하고 `_detail`을 겹친다. 검정 윤곽과 하이라이트를 보호하며, 버블티는 펄·빨대를 제외한 음료만 색칠한다.
- 덤벨·골프채: 제공된 tint 마스크가 거의 비어 있어 명도 기반 금속 마스크를 런타임에 만든다.
- 의상: `MaterialTint`에서 옷감의 색역을 골라 MULTIPLY tint를 적용한다. 망고 피부·잎과 주요 장식을 보호하고 결과는 메모리 캐시에 보관한다.

색상 ID는 `상품ID__색상코드`로 저장하며 기존 원본 ID는 계속 지원한다.
색이 달라도 baseId가 같으면 같은 상품을 보유한 것으로 판정해 중복 구매를 막는다.
보유 상품의 색 변경은 무료이며, 해당 상품을 장착 중이면 홈에도 즉시 반영된다.
망고집에 이미 보관된 망고의 색은 바뀌지 않는다.

검증: 단위 테스트 24개, Android 저장·렌더링 테스트 6개 통과.
렌더링 테스트에서 모든 의상의 색 변화와 피부·잎 보호, 버블티·금속 tint 표시를 확인한다.
