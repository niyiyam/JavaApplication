# 이미지 상점 구성

기준 브랜치: feature/prototype (`775dd9e`)
작업 브랜치: codex/shop-image-assets

## 가져온 이미지

원본은 별도 테스트 프로젝트 `Mangofit_mangotest1/app/src/main/res/drawable-nodpi`에 있다.
원본을 수정하지 않고 PNG 48개를 같은 리소스 디렉터리로 복사했다.

- 노란 기본 망고 + 노란 망고 의상 10종 (11개)
- 기본 미소 표정 (1개)
- 손 아이템 18종 × 좌우의 `_preview` 이미지 (36개)

성장 단계별 자동 색상 변경, 표정 선택, 아이템 색상 변경은 이번 구현에 포함하지 않는다.
의상 PNG는 몸체까지 포함하므로 본체 이미지 자체를 교체하고 표정을 겹친다.
손 아이템은 테스트 프로젝트의 기본 배치를 망고 이미지 너비 기준 비율로 옮겼다.
개별 아이템 배치는 `ItemCatalog`의 `Placement`에서 조정한다.

## 상품과 가격

새 의상 10종, 오른손 18종, 왼손 18종을 판매한다. 기존 모자 6종은 유지한다.
임시 가격은 일반 의상 500, 곤룡포 800, 손 아이템 각 300 이파리다.
좌우 아이템은 별도 상품으로 구매하고 각각 장착한다.
`ItemCatalog`에서 가격·배치를, `strings.xml`에서 상품명을 관리한다.

상품 카드를 누르면 현재 장비와 함께 착용 미리보기를 볼 수 있다.
가격 버튼에서 구매를 확인하고, 보유 중 버튼을 누르면 꾸미기 화면으로 이동한다.
꾸미기에서 적용하면 홈·기록·망고집의 공통 `MangoView`에도 반영된다.

## 저장 호환성

기존 `hat`, `top`, `hand` 키와 아이템 ID는 유지한다. `hand`는 오른손 슬롯이다.
왼손은 SharedPreferences의 `equip_left_hand`, 보관 JSON의 `left_hand`에 저장한다.
예전 저장 파일에 왼손이 없으면 미장착 상태로 읽는다.
기존 상의·손 아이템은 신규 판매 목록에서 제외하되, 보유 목록과 장착은 유지한다.
기존 보관 시 아이템 소모 규칙은 왼손에도 동일하게 적용한다.
